# وودش (Woodesh)

داشبورد مانیتورینگ و تحلیل فروش برای **WordPress + WooCommerce** — ساخته‌شده توسط [404dev](https://404dev.it).

داشبورد مانیتورینگ و تحلیل فروش برای **WordPress + WooCommerce** با رابط کاربری تیره، RTL و فارسی.

فروش کل در کارت‌های KPI برابر **فروش خالص (Net Sales)** است: مجموع مبلغ سفارش‌های معتبر منهای مرجوعی‌های همان بازه. سفارش‌های لغوشده (`cancelled`) و ناموفق (`failed`) به‌صورت پیش‌فرض در فروش لحاظ نمی‌شوند.

## امکانات

- KPI با مقایسه دوره قبل و درصد رشد + گرید Bento با کارت ویژه فروش خالص
- بازه ۷ / ۳۰ / ۹۰ روز، ۱ سال و بازه سفارشی شمسی
- نمودار فروش / سفارش / میانگین سفارش (خطی و میله‌ای) با فیلتر وضعیت پویا — رنگ‌ها از تم فعلی
- ۶ تم رنگی (وودش، اقیانوس، زمرد، رز، غروب، گرافیت) × حالت شب/روز — پیش‌فرض همان تم تیره بنفش
- سفارشات اخیر با صفحه‌بندی و مرتب‌سازی
- محصولات پرفروش، مشتریان برتر، فروش دسته، روش پرداخت، Heatmap ساعتی
- هشدار موجودی کم (با پشتیبانی از آستانه اختصاصی هر محصول)، هدف فروش روزانه، مرکز اعلان با پاکسازی خودکار
- ویجت Admin Bar با رفرش دوره‌ای، خروجی CSV امن، کش نسخه‌بندی‌شده
- رفرش خودکار داشبورد با فاصله قابل انتخاب (توقف در تب غیرفعال مرورگر)
- صفحه ورود/ثبت‌نام اختصاصی فارسی برای وردپرس و ووکامرس (خاموش به‌صورت پیش‌فرض، فعال‌سازی از تنظیمات)
- صفحه تنظیمات تب‌دار و تمیز: عمومی، ظاهر، اعلان‌ها، صفحه ورود، پیشرفته

## نیازمندی‌ها

- WordPress 6.2+
- PHP 7.4+
- WooCommerce 7.0+

## نصب

1. پوشه `salesbin` را زیپ کنید.
2. در وردپرس: افزونه‌ها → افزودن → بارگذاری افزونه.
3. افزونه را فعال کنید (WooCommerce باید فعال باشد).
4. منوی **وودش** در پیشخوان ظاهر می‌شود. صفحه اصلی پیشخوان وردپرس نیز همین کارت‌ها را با تم تیره نشان می‌دهد.

## معماری

- Bootstrap: `salesbin.php` + `Salesbin_Plugin`
- لایه داده: `Salesbin_Order_Query` با اولویت `wc_order_stats` → HPOS `wc_orders` → `wp_posts`
- REST: `salesbin/v1/*` با nonce و `manage_woocommerce`
- فرانت: Vanilla JS (SPA-like) بدون React و بدون CDN
- اعلان‌ها: جدول سفارشی `{prefix}salesbin_notifications`

جدول گزارش تجمیعی جداگانه ساخته نشد؛ جداول lookup ووکامرس برای فروشگاه‌های بزرگ کافی و سازگار با HPOS هستند.

## REST API

پایه: `/wp-json/salesbin/v1/`

| Method | Route | توضیح |
| --- | --- | --- |
| GET | `/bootstrap` | بسته‌ اولیه |
| GET | `/stats` | KPI |
| GET | `/sales-chart` | سری زمانی |
| GET | `/orders` | لیست سفارش |
| GET | `/products` | محصولات پرفروش |
| GET | `/customers` | مشتریان برتر |
| GET | `/categories` | فروش دسته |
| GET | `/payments` | درگاه‌ها |
| GET | `/heatmap` | ساعت اوج |
| GET | `/stock` | موجودی کم |
| GET | `/goal` | هدف روزانه |
| GET | `/admin-bar` | ویجت نوار |
| GET | `/notifications` | اعلان‌ها |
| POST | `/notifications/{id}/read` | خوانده شد |
| POST | `/notifications/read-all` | همه خوانده شد |
| GET/POST | `/settings` | تنظیمات |

Query: `range` (`7d`,`30d`,`90d`,`1y`,`custom`)، `start`/`end` (`Y-m-d` میلادی)، `status`.

پاسخ موفق:

```json
{ "success": true, "data": {}, "meta": {} }
```

خطا:

```json
{ "success": false, "code": "salesbin_invalid_date_range", "message": "..." }
```

احراز هویت: کاربر واردشده + قابلیت `manage_woocommerce` + هدر `X-WP-Nonce` (`wp_rest`).

## کش

- کلید: `salesbin_{prefix}_v{version}_{hash}`
- نسخه در option `salesbin_cache_version`
- با رویدادهای سفارش/محصول/موجودی/refund فقط نسخه Salesbin بالا می‌رود (نه کل کش سایت)

## هوک‌ها و فیلترها

- `salesbin_required_capability`
- `salesbin_can_view_customer_pii`
- `salesbin_sales_statuses`
- `salesbin_attention_statuses`
- `salesbin_login_methods` — تب‌های احراز هویت صفحه ورود (پسورد، SMS و…)
- `salesbin_login_otp_ready` / `salesbin_login_otp_send` / `salesbin_login_otp_verify` — فاندیشن ورود با کد پیامکی (مثل ملی‌پیامک) برای نسخه‌های بعد
- هوک‌های WC برای ابطال کش: `woocommerce_new_order`, `woocommerce_order_status_changed`, `woocommerce_update_order`, `woocommerce_order_refunded`, `woocommerce_product_set_stock`, …

### پنل حساب کاربری (بازطراحی My Account) — اختیاری

- پیش‌فرض خاموش؛ فعال‌سازی از «تنظیمات → پنل حساب». برای بازگشت به UI پیش‌فرض کافی است تیک را بردارید.
- **بدون هدر اختصاصی:** هدر سایت با قالب/المنتور شما نمایش داده می‌شود؛ پنل فقط سایدبار + محتوا است. در موبایل یک دکمه‌ی شناور (FAB) درایور منو را باز می‌کند.
- **تمام‌عرض:** پنل از کانتینر قالب خارج و لبه‌به‌لبه رندر می‌شود (قاب داخلی ۱۵۶۰px برای مانیتورهای بزرگ) — دیگر در کانتینر باریک قالب فشرده نمی‌شود.
- **جانشینی تضمینی از پنل قالب:** جراحی هوک‌ها در آخرین لحظه (template_redirect) انجام می‌شود تا حتی قالب‌هایی که رندرکننده‌ی خودشان را دیرتر ثبت می‌کنند هم جایگزین شوند؛ به‌علاوه قالب داخلی my-account.php پلاگین سرو می‌شود. فرم‌های قالب دست‌نخورده می‌مانند. خروج اضطراری: `?woodesh-account=0`.
- **بازسازی صفحه حساب:** اگر صفحه «حساب کاربری من» حذف شده باشد، دکمه‌ی «بازسازی» در تنظیمات آن را دوباره می‌سازد و به ووکامرس وصل می‌کند.
- **طراحی شیشه‌ای (Glassmorphism):** کارت‌ها و سایدبار با شفافیت + blur + ساشوره‌ی رنگی، هدر شیشه‌ای چسبان، حباب‌های گرادیانی متحرک در پس‌زمینه، ورود پلکانی کارت‌ها (staggered) و موشن‌های سبک با احترام به prefers-reduced-motion.
- **جانشینی تضمینی از پنل قالب:** هنگام فعال‌سازی، پلاگین قالب `myaccount/my-account.php` خودش را سرو می‌کند (bypass کردن override قالب) و همه‌ی رندرکننده‌های رقیب ناوبری/داشبورد را از هوک‌ها حذف می‌کند — پنل اختصاصی قالب‌ها جایگزین پنل وودش می‌شود، اما فرم‌ها و partialهای قالب (myaccount/forms/*.php) همچنان از خود قالب لود می‌شوند. خروج اضطراری: `?woodesh-account=0`.
- **افزودن اپشن بدون کد:** تنظیمات → پنل حساب → «لینک‌های اختصاصی داشبورد کاربر» — هر خط «عنوان | آدرس» یک کارت دسترسی سریع جدید می‌سازد. برای اپشن‌های توسعه‌ای: `salesbin_account_widgets` و `salesbin_account_stats`.
- چیدمان مشابه uPanel با داده‌ی واقعی ووکامرس (مجموع خرید، تعداد سفارش، دانلودها، عضویت، وضعیت سفارش‌ها، سفارش‌های اخیر، پیام‌های مهم) و empty state واقعی.
- آیکون‌های Font Awesome 6.5.2 Free باندل‌شده‌ی لوکال (بدون CDN)؛ چهار فونت فارسی لوکال با سوییچر مستقل برای پنل مدیر و پنل کاربران.
- ریسپانسیو چهار سطح (1200/992/782/480): سایدبار موبایل به دراور شیشه‌ای تبدیل می‌شود.
- آمار در کش ۵ دقیقه‌ای per-user با ابطال بر اساس رویدادهای سفارش.

### تم کل پیشخوان وردپرس

با تنظیم «اعمال تم وودش روی کل پیشخوان» (پیش‌فرض فعال)، منوی ادمین، نوار مدیریت، کارت‌ها، جدول‌ها، فرم‌ها، دکمه‌ها و نوتис‌ها در **همه‌ی صفحه‌های مدیریتی** با پالت وودش تم می‌شوند — پالت به‌صورت سمت سرور روی body چاپ می‌شود (بدون وابستگی به JS) و حالت روشن هم دارد. صفحات خود وودش همچنان با سوئیچ زنده‌ی تم/حالت theme.js کار می‌کنند.

## تم‌ها و حالت شب/روز

تم‌ها با CSS Variables روی `body[data-sb-theme][data-sb-mode]` پیاده شده‌اند. انتخاب کاربر در localStorage ذخیره می‌شود؛ پیش‌فرض از تنظیمات می‌آید. تم پیش‌فرضِ شب همان پالت بنفش نسخه‌های قبلی است. همه‌ی رنگ‌های نمودار/Heatmap/پیشرفت از متغیرهای تم خوانده می‌شوند و با تغییر تم بلافاصله رندر می‌شوند.

## صفحه ورود و ثبت‌نام

- پیش‌فرض خاموش. با فعال‌سازی، **یک آدرس واحد** است: `/my-account/` — مهمان فرم ورود اختصاصی وودش را می‌بیند و بعد از ورود همان آدرس به پنل کاربری اختصاصی تبدیل می‌شود. لینک جداگانه‌ای وجود ندارد. لینک قدیمی `/my-account/woodesh-login` و شورت‌کد `[salesbin_login]` همچنان کار می‌کنند.
- **مستقل از پیامک:** ورود و ثبت‌نام با نام کاربری/ایمیل و رمز عبور بدون هیچ تنظیم ملی‌پیامک کار می‌کند؛ روش موبایل فقط وقتی اطلاعات پنل ثبت شده باشد ظاهر می‌شود.
- **دیزاین شیشه‌ای وودش:** کارت شیشه‌ای با بک‌دراند گرادیانی متحرک، حالت شب/روز واقعی (سمت سرور + تاگل محلی)، تب‌های لغزان ورود/ثبت‌نام.
- **بازسازی صفحه:** دکمه‌ی «بازسازی صفحه ورود و ثبت‌نام» در تنظیمات، صفحه «حساب کاربری من» را می‌سازد/متصل می‌کند و لینک‌ها را تازه می‌کند.
- ریدایرکت بعد از ورود همیشه به حساب کاربری است؛ مقدار صریح `redirect_to` اعتبارسنجی می‌شود.

### ورود با کد پیامکی (ملی‌پیامک) — اختیاری

- کاملاً آپشنال و مستقل از خود صفحه ورود: بدون آن هم ورود رمزی کار می‌کند؛ تا زمانی که «فعال‌سازی ورود با کد پیامکی» زده نشود هیچ روتی لود نمی‌شود.
- **فلوی یکپارچه:** هر شماره معتبر کد می‌گیرد (بدون افشای ثبت‌شده/نشده بودن) و در صورت ثبت‌نام نبودن، حساب به‌صورت خودکار ساخته می‌شود (قابل غیرفعال‌سازی + احترام به `users_can_register`).
- کلاینت ملی‌پیامک مطابق SDK رسمی بازنویسی شده (github.com/Melipayamak/melipayamak-php): `SendSMS`، `BaseServiceNumber` با `text/to/bodyId`، `GetCredit` با `UserName/PassWord` — موفقیت فقط با `RetStatus == 1` و `Value` به‌عنوان recId/کد خطا. ارسال همیشه از فکتوری `Salesbin_SMS::provider()` می‌گذرد (تعویض درگاه با فیلتر `salesbin_sms_provider`).
- کاربران واقعی WP (متای `salesbin_phone`، سازگار با `billing_phone`)، کدها با HMAC-SHA256 در transients، سقف تلاش (۵)، اعتبار/کول‌داون قابل تنظیم از تنظیمات (پیش‌فرض ۱۸۰/۶۰ ثانیه)، سهمیه‌ی ساعتی هر IP (۱۰).
- دیکشنری کامل خطاهای پنل به فارسی (خطا از RetStatus و در نبودش از Value استخراج می‌شود)، حالت تست، تشخیص IP امن پشت Cloudflare، ماسک شماره در لاگ‌ها.
- REST: `POST salesbin/v1/login/sms/send` و `POST salesbin/v1/login/sms/verify` (بدون type؛ ریدایرکت اختیاری `redirect_to`).

## امنیت

- بررسی `ABSPATH`
- Capability روی صفحات و REST
- Nonce برای REST و Export
- SQL فقط با `$wpdb->prepare`
- خروجی HTML با `esc_*`
- CSV با BOM و جلوگیری از formula injection

## سازگاری HPOS

افزونه HPOS را اعلام می‌کند. تجمیع روی `wc_orders` / `wc_order_stats` است نه فرض `wp_posts`. لیست سفارش از `wc_get_orders` استفاده می‌کند.

## عیب‌یابی

- داشبورد خالی: WooCommerce فعال باشد و کاربر `manage_woocommerce` داشته باشد.
- داده صفر: وضعیت سفارش در مجموعه فروش پیش‌فرض نیست.
- Heatmap نادرست: timezone وردپرس را بررسی کنید.
- لاگ: تنظیم «ثبت لاگ توسعه» یا `WP_DEBUG`.

## توسعه

ساختار کلاس‌ها در `includes/` است. Autoloader در `includes/class-autoloader.php`. دارایی‌ها در `assets/` بدون bundler.

متن دامنه ترجمه: `salesbin`.

## محدودیت‌های شناخته‌شده

- رتبه‌بندی مشتریان برای بازه‌های شلوغ حداکثر ۵۰۰ سفارش اخیر بازه را اسکن می‌کند (برای جلوگیری از بارگذاری کل تاریخچه در RAM).
- Heatmap از offset ثابت timezone در شروع بازه استفاده می‌کند (برای ایران بدون DST مناسب است).
- تصویر مرجع فقط الهام UI است و داخل داشبورد قرار نگرفته.

برای سناریوهای تست به `TEST-PLAN.md` مراجعه کنید.
